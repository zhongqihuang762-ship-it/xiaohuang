# SPO 科技体能训练开源实验室

这是一个可在浏览器中运行的技术演示基线，围绕 SPO 科技体能训练中心的三个业务方向：

1. **AI 运动表现评估**：人体骨架可视化、跳跃阶段识别、跳跃高度与腾空时间估算、落地膝角和左右差异。
2. **AI 体态与动作筛查**：肩线、髋线、躯干和膝角差异的实时观察提示。
3. **神经反应训练**：简单反应、九宫格选择反应、顺序记忆，以及反应时、正确率和综合得分报告。

## 运行

无需构建工具。进入项目目录后启动本地静态服务器：

```bash
npm run serve
```

浏览器打开 `http://localhost:8080`。摄像头权限通常只允许在 HTTPS 或 localhost 环境使用。首次启用视觉识别时，需要联网加载 TensorFlow.js、MoveNet 模型与相关运行文件。

无需摄像头也可以先体验“神经反应训练”模块。视觉模块同时支持摄像头和本地视频。

运行指标测试：

```bash
npm test
```

## 我们自主完成的部分

- 三模块产品结构与红黑白视觉界面；
- 跳跃标定、阶段记录、关节角、左右差异与单目位移估算逻辑；
- 体态与动作筛查指标、阈值提示和非医疗化报告表达；
- 三类神经反应训练任务、计时、正确率、综合评分与 JSON 报告；
- 浏览器端本地视频处理与系统集成。

## 使用的开源底座

人体关键点识别使用 TensorFlow.js 的 MoveNet。上游项目为 `tensorflow/tfjs-models`，采用 Apache-2.0 许可证。完整来源与许可说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

本仓库没有将上游关键点模型宣称为团队原创。项目团队的工作位于业务场景、指标引擎、训练任务、交互、报告和系统集成层。

## 技术边界

- 摄像头能够估算**运动学**数据，如关节位置、角度、相对位移和时序；不能直接测得地面反作用力、冲量和功率。
- “跳跃高度”是经身高标定后的单目视觉估算，会受拍摄距离、镜头角度、遮挡和动作方式影响。
- 体态结果是运动训练观察提示，不是疾病、损伤或康复诊断。
- 若接入真实测力台，本项目可作为视频同步、关节角分析和报告展示层。

## 建议的比赛表述

> 项目团队自主完成三套体育场景应用的业务定义、指标计算、训练任务、交互界面、报告和系统集成；人体关键点识别采用合规的开源算法框架，并在仓库中公开注明来源和许可证。

这比“全部算法从零原创”更准确，也更经得住代码、许可证和技术边界追问。

## 数据与隐私

当前演示在浏览器端处理摄像头和本地视频，不主动上传视频。真实部署仍需补充账号权限、未成年人监护人授权、数据保留期限、删除机制和安全审计。
