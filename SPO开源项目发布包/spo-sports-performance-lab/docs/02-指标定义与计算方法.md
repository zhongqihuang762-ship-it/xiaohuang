# 指标定义与计算方法

## 一、关键点与置信度

MoveNet 输出 17 个关键点。当前演示仅使用置信度不低于 0.25 的点参与绘制和计算。正式版本应根据机位、光线和动作类型重新标定阈值，并对连续帧做异常值剔除。

## 二、关节角

对关节中点 `B` 及其相邻点 `A、C`，计算向量 `BA` 与 `BC` 的夹角：

```text
θ = arccos((BA · BC) / (|BA| × |BC|))
```

膝角使用髋—膝—踝三点。左右膝差为两侧膝角的绝对差值。

## 三、肩髋倾斜和躯干侧倾

- 肩线倾斜：左右肩连线相对水平线的角度；
- 髋线倾斜：左右髋连线相对水平线的角度；
- 躯干侧倾：肩中点—髋中点连线相对竖直方向的角度。

镜像显示不会改变角度绝对值。系统对接近 180° 的水平连线进行归一化，输出 `-90°～90°` 范围。

## 四、跳跃高度估算

静止标定阶段以多帧中位数建立基线。根据输入身高和画面中的人体像素高度建立比例：

```text
厘米/像素 = 输入身高(cm) / 静止人体像素高度(px)
跳跃高度估算 = (静止髋Y - 峰值髋Y) × 厘米/像素
```

这是单目比例估算，不是实验室级三维位移。镜头俯仰、拍摄距离改变、人体前后移动、遮挡和屈髋动作都会影响结果。

## 五、腾空时间估算

系统以静止踝点基线为参考，当双踝平均位置超过动态阈值时标记离地，回落后标记落地。腾空时间为离地首帧至落地帧的时间差。

正式版本建议同时使用脚尖关键点、速度变化和连续帧状态机，以减少屈膝抬脚造成的误判。

## 六、体态对称分

当前原型以 100 分为起点，根据肩线、髋线、躯干和膝角差异加权扣分。权重用于产品演示，尚未经过大样本常模验证，因此不能称为医学量表或国家标准。

## 七、神经反应综合分

综合分由正确率和平均反应时构成：

```text
综合分 = 正确率得分 × 55% + 速度得分 × 45%
```

速度得分在 300～1500ms 的演示区间内归一化。不同年龄和项目应建立独立常模，不宜直接横向比较儿童与成年运动员。
