# 数据与隐私原则

## 一、当前开源演示

- 视频与关键点在浏览器本地处理；
- 不主动上传摄像头画面和本地视频；
- 神经反应报告由用户主动下载到本地；
- 不包含账号系统、云数据库或人脸识别。

## 二、真实运营需要补齐的制度

涉及未成年人时，应在采集前取得监护人的明确、可证明授权，并以易懂方式说明：

- 采集哪些信息；
- 用于何种测评或训练；
- 保存在哪里、保存多久；
- 谁可以查看；
- 如何撤回授权和删除数据；
- 是否用于宣传、科研或模型训练。

训练服务授权与照片、视频公开使用授权应分开，不应以参加训练默认同意宣传使用。

## 三、最小化原则

- 只采集完成训练所必需的数据；
- 报告优先使用学员编号，减少公开姓名和联系方式；
- 默认不保存原始视频，确需留存时明确期限；
- 教练、机构管理员和技术人员采用最小权限；
- 对导出、删除和异常访问保留审计记录。

本文件是产品设计原则，不构成针对具体地区和业务的法律意见。正式上线前应由专业人员结合实际部署地审查。
