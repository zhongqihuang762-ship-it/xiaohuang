# 产品迭代路线

## V0.1：开源演示基线（当前）

- 单人实时骨架；
- 跳跃静止标定与单次记录；
- 四类体态/动作对称指标；
- 三种神经反应任务；
- 本地 JSON 报告；
- 指标单元测试和开源许可说明。

## V0.2：可用性增强

- 上传视频逐帧分析；
- 起跳、腾空、落地状态机优化；
- 多次跳跃趋势和左右对比；
- 体态动作协议：深蹲、弓步、单腿蹲、上肢活动度；
- 九宫格脚步训练的摄像头区域识别；
- PDF 训练报告。

## V0.3：机构训练闭环

- 学员档案与教练权限；
- 训练前测—处方—课程—复测；
- 年龄、运动项目和训练阶段分层；
- 指标版本管理和审计；
- 监护人授权、数据删除和导出机制。

## V1.0：软硬件融合

- 与真实测力台同步，融合力、冲量、功率和关节角；
- 双机位或深度相机提高空间估算稳定性；
- 外部反应灯、触摸屏和传感器接入；
- 经样本验证的常模、信度和重测误差；
- 多门店运营、设备状态与服务质量管理。
